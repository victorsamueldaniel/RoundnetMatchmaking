# Code of Conduct

## Our Standards
Contributors are expected to:
- Be respectful and constructive.
- Assume good intent.
- Provide technical feedback without personal attacks.
- Help keep discussions focused on project outcomes.

Unacceptable behavior includes harassment, discriminatory language, threats, or doxxing.

## Enforcement
Project maintainers may remove comments, close discussions, or block contributors for violations.

## Scope
This policy applies to repository discussions, issues, pull requests, and related project communication.
