# Security Policy

## Reporting a Vulnerability
If you discover a security issue, do not open a public issue.

Please use one of these options:
1. Open a private GitHub Security Advisory.
2. Contact the maintainers through a private channel.

Include:
- A clear description of the issue.
- Reproduction steps.
- Potential impact.
- Suggested mitigation, if known.

## Response Targets
- Initial acknowledgment: within 5 business days.
- Triage decision: within 10 business days.
- Fix timeline: based on severity and release risk.
